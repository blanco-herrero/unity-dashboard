# UNITY methods dashboard

Repository: https://github.com/blanco-herrero/unity_methods
Dashboard: https://blanco-herrero.github.io/unity_methods/

## Interpretation
Reference lines are unweighted medians of method means. Fixed overview medians do not move with category filters; selected-objective medians use plotted methods after filtering.
Objective-participant timeliness is not directly objective-specific. It includes people selecting the objective who rated the method irrespective of method relevance selection. Differences can reflect respondent composition.
Bubble area represents evidence-assessment count, not statistical precision. With within-objective scaling, largest bubbles match the 100-assessment reference area but are not comparable across objectives. Missing evidence can have multiple causes and is not plotted at zero.
